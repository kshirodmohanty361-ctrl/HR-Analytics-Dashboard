# HR Analytics Dashboard

## 📊 Project Overview

This project is an interactive HR Analytics Dashboard created using Microsoft Power BI.

The dashboard provides insights into employee attrition, workforce demographics, departments, job roles, and employee-related trends.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Excel
- Data Visualization

## 🎯 Key Objectives

- Analyze employee attrition
- Understand employee demographics
- Analyze department and job role performance
- Identify important HR trends
- Track employee-related KPIs
- Support data-driven HR decision making

## 📈 Dashboard Features

- Total Employees
- Attrition Rate
- Active Employees
- Department Analysis
- Job Role Analysis
- Gender Analysis
- Age Group Analysis
- Job Satisfaction Analysis
- Interactive Filters and Slicers
